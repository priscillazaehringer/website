# Lead Stream assets

Hero images for `/lead-stream`. Add the two files here with these exact names:

- `hero-flowers.jpg` — the daisies-on-yellow flatlay (hero left slot)
- `hero-priscilla.jpg` — the black-and-white portrait of Priscilla at her desk (hero right slot)

How to add them (GitHub web): open this `assets/` folder → **Add file → Upload files** →
drag the two images in → name them exactly as above → commit. They'll show up in the
hero automatically on the next deploy.

Prefer WordPress? Upload both to your media library instead and send the two URLs, and
the hero `<img src="...">` tags in `lead-stream.html` can point at those instead.
